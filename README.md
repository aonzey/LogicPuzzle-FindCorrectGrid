# 逻辑推理游戏：找出正确格子

一个基于网页的逻辑推理游戏，玩家需要通过逻辑推理找出网格中正确位置的格子。

## 项目描述

这是一个单页HTML逻辑推理游戏。游戏目标是在一个 N×N 的网格中找出所有正确位置的格子。每个颜色的区块中只有一个正确格子，每行每列有且仅有一个正确格子，且正确的格子互不相邻。
https://aonzey.github.io/LogicPuzzle-FindCorrectGrid/

## 代码结构说明

### 1. index.html
主HTML文件，包含：
- 游戏控制面板（地图尺寸、唯一解选项、自动标记选项）
- 游戏状态显示（生命值、计时器、剩余格子数）
- 游戏网格容器
- 操作提示和游戏规则说明
- 外部CSS和JS文件引用

### 2. css/styles.css
所有样式定义，包括：
- CSS变量定义（格子大小、面板背景、主色调）
- 控制面板样式
- 游戏网格和格子样式
- 颜色配色方案（10种不同颜色）
- 动画效果（错误抖动动画）
- 响应式设计（手机屏幕适配）
- 暂停状态样式

### 3. js/game.js
游戏核心逻辑，包含：
- 游戏状态管理变量
- 游戏初始化函数（`preInit()`, `initGame()`）
- 布局生成算法（`generateLayout()`）
- 唯一解验证（`isUnique()`）
- 网格渲染逻辑（`renderGrid()`）
- 用户交互处理（`handleCellClick()`, `handleReveal()`）
- 提示系统（`givePonyHint()`, `giveMarkHint()`）
- 自动标记功能（`autoMarkInvalidCells()`）
- 游戏结束处理（`finishGame()`）
- 暂停/继续功能（`togglePause()`）

## 功能特性

1. **可调节难度**：支持4-15的地图尺寸
2. **唯一解选项**：可勾选确保生成的地图只有唯一解
3. **自动标记**：开启后，每当找到一个正确格子，系统自动标记同行、同列和相邻的格子为错误
4. **提示系统**：
   - 自动翻牌提示：随机翻开一个正确格子
   - 自动标记提示：随机标记3个错误格子
5. **暂停功能**：游戏过程中可暂停计时
6. **计时系统**：根据地图尺寸动态调整时间限制
7. **生命值系统**：初始3条生命，错误选择会扣除生命值
8. **触控优化**：移动端支持单击标记、双击确认操作
9. **响应式设计**：自动适配不同屏幕尺寸

## 游戏规则

1. 每种颜色区块中仅有一个正确格子
2. 每行每列有且仅有一个正确格子
3. 正确的格子互不相邻（包括对角线方向）

## 操作方法

- **单击格子**：标记/取消标记（显示✕）
- **双击格子**：确认选择（显示🌹）
- **暂停按钮**：暂停/继续游戏
- **重开按钮**：重新生成新地图
- **自动翻牌提示**：随机揭示一个正确格子
- **自动标记提示**：随机标记3个错误格子

## 技术实现

- 纯原生JavaScript实现，无外部依赖
- 使用CSS Grid布局实现游戏网格
- 回溯算法生成有效布局
- 深度优先搜索验证唯一解
- 响应式设计，支持移动端和桌面端

## 运行方法

直接用浏览器打开 `index.html` 文件即可运行游戏。

## 浏览器兼容性

支持所有现代浏览器（Chrome, Firefox, Safari, Edge等）。
